# 뚝딱 PRD

## 1. 프로젝트 개요
뚝딱은 유지보수가 필요한 사용자와 작업 가능한 사용자를 연결하는 유지보수 요청 플랫폼입니다.

전기, 설비, 누수, 도어락, 생활 수리 등 일상 속 문제를 사용자가 등록하고, 작업자가 요청을 확인하고 수락한 뒤 진행 상태를 관리할 수 있도록 구성했습니다.

## 2. 문제 정의
생활 수리와 유지보수 요청은 전화나 메신저로 전달되는 경우가 많아 요청 내용, 담당자, 진행 상태를 체계적으로 관리하기 어렵습니다.

뚝딱은 요청 등록부터 작업 수락, 진행, 완료까지의 과정을 하나의 서비스 흐름으로 연결하는 것을 목표로 합니다.

## 3. 목표 사용자

### 요청자
생활 수리 또는 유지보수가 필요한 사용자

### 작업자
등록된 요청을 확인하고 작업을 수행할 수 있는 사용자

## 4. 핵심 목표
- 사용자가 유지보수 요청을 간편하게 등록할 수 있도록 구성
- 작업자가 요청을 확인하고 수락할 수 있도록 구성
- 요청자와 작업자가 진행 상태를 확인할 수 있도록 구성
- 로그인 상태와 사용자 역할에 따라 화면과 기능을 분리
- 실제 서비스와 유사한 사용자 흐름 구현

## 5. 주요 기능

### 회원가입 및 로그인
- 이메일 회원가입 및 로그인
- Google 소셜 로그인
- Kakao 소셜 로그인
- 로그인 상태 유지

### 요청 등록
- 요청 제목
- 카테고리
- 작업 장소
- 상세 내용 등록

### 요청 조회
- 전체 요청 조회
- 내가 등록한 요청 조회
- 내가 맡은 작업 조회

### 요청 상세 및 작업 수락
- 요청 상세 정보 확인
- 작성자 및 담당자 확인
- 작업 수락
- 요청 상태 변경

### 마이페이지
- 사용자 정보 확인
- 이름 수정
- 비밀번호 변경
- 내 요청 및 맡은 작업 확인
- 로그아웃 및 계정 설정

## 8. AI 코딩 도구 활용
ChatGPT, Claude, Claude Code 등 AI 코딩 도구를 활용해 요구사항을 구체화하고 기능을 컴포넌트 및 작업 단위로 나누어 개발했습니다.

AI가 생성한 코드를 그대로 사용하는 방식이 아니라 직접 실행하고 오류를 확인했으며, 프로젝트 구조와 서비스 흐름에 맞게 수정하고 개선했습니다.

주요 활용 영역은 다음과 같습니다.

- 프로젝트 요구사항 정리
- 화면 및 사용자 흐름 설계
- 컴포넌트 구조 설계
- 인증 및 상태 분기 로직 검토
- 오류 원인 분석
- 코드 구조 정리
- README 및 문서 작성
